# 华山战力查询

> 查询华山论剑（狼人杀）选手战力、战绩与单局复盘的桌面小工具。

一个单文件 Windows 程序：从本机**电脑版微信**读取你的登录令牌，在本地启动一个内存服务，把一张内嵌网页发送到浏览器，并在 Go 端**代理华山官方接口**（注入令牌、分页拉全、错误归一）。浏览器只与本地服务通信；令牌平时不会下发到页面，只有用户明确点击“复制 Token”时才短暂读取。发布物是**单个 `.exe`**，免安装、免配置。

```
电脑版微信(本地令牌)  →  Go 启动器  →  本地内存服务(/api/*)  →  浏览器页面
                              │
                              └─ 代理 v2.huashan.tv 官方接口（令牌只在此注入）
```

---

## 功能

- **选手搜索**：按选手名搜索，展示头像、门派与总分；也支持直接输入**选手 ID** 直达。
- **作用域筛选**：赛区 / 赛季 / 门派三级筛选，候选项互相联动。
- **数据面板**：综合 / 好人局 / 狼人局聚合指标，以及可排序的角色表现表（场次 / 场均分 / 胜率 / MVP / 尽力 / 背锅）；选定门派时按逐场现算。
- **选手头部**：照片 + 姓名 / 编号 + 战力值 + 关键指标（总场次、场均分、胜率、投狼率、站对边率）+ 荣誉徽标 + 门派标签。
- **逐场战绩**：按日期 / 得分排序；身份 / 门派 / 结果 / 阵营 / 标记（MVP·尽力·背锅）多维筛选；对局较多时分批加载。
- **单局复盘弹层**（「按人」/「按天」两种视图）：
  - 花名册（狼队 / 神职 / 平民）、出局时间线与死因、违规扣分。
  - 每日技能动作：预言家验、女巫救 / 毒、守卫守、猎人带、摄梦、梦魇恐惧、狼美人魅惑、猎魔人狩猎、石像鬼查验、骑士决斗、侦探翻牌、怪盗狼王顶盾；狼刀按同目标合并。
  - 每日投票：按被投目标归并（同投一人合并成行），箭头按投狼 / 投好人着色；含警徽竞选与放逐结果 / 平安白天。
  - 阵营三色配色（狼红 / 神蓝 / 民灰）。
- **多人对比**（对比篮，最多 12 人）：把多名选手加入对比篮，在一张表里横向对比、点列头排序。
  - **按阵营**：综合 / 好人 / 狼人。
  - **按身份**：`人 × 身份`矩阵（选一个指标，一屏看谁擅长哪个身份）或 `单个身份`（选一个身份比多项指标）。
  - 全体共享赛区 / 赛季范围，可勾选行聚焦子集，点选手名下钻单人详情；「按身份」数据后台预热、切页秒显。
- **主题与说明**：深色 / 浅色主题切换，内置使用说明、分享给朋友与反馈入口，⚙ 菜单显示版本号。
- **令牌自愈**：令牌过期时页面提示，回微信重开战力页后一键刷新，无需重启程序。

## 使用（面向普通用户）

从发行版页下载 `huashan-query-vX.Y.Z.exe` 这**一个文件**即可运行（静态单文件、免装环境；页面已内嵌，磁盘不生成 `.html`；不含任何人的令牌）。想推荐给朋友，直接把下载链接发给对方即可——程序 ⚙ 菜单「分享给朋友」会帮你把简介和下载地址复制好。

1. 在**电脑版微信**里打开自己的『华山战力页』并登录一次（令牌约 1 天有效）；**登录后关掉该页**，微信才会把令牌写入本地，程序才能读到。
2. 双击 `.exe`，它会**自动打开浏览器**进入查询页。程序在后台运行，**没有命令行 / 控制台窗口**。
3. 令牌过期后：回微信重新打开一次战力页并关掉，再回网页点『我已登录，重新检测』（无需重开程序）。
4. 如果程序始终无法从本机微信检测到令牌，可在登录提示页手动粘贴一枚有效 Token；它只保存在本次程序的内存中，关闭即清除。
5. 退出程序：点页面右上角 ⚙ 菜单里的『🚪 退出程序』立即退出；或直接关闭浏览器页面，程序会在约 3 分钟后自动退出。

> **数据是打开程序时抓取的快照，不会自动更新。** 怀疑数据过期时，关掉程序重新打开即可。
>
> 出问题时，`.exe` 同目录会生成 `huashan-query.log`（仅记录错误，英文，含调用栈），发给作者即可。

## 开发

**环境要求**：Go 1.24+、Node.js（仅用于跑前端测试）、Windows（读取微信本地存储）。项目**零第三方依赖**（纯标准库）。

```bash
go run .              # 本地起服务并打开浏览器（用你自己的微信令牌代理官方接口）
go test ./...         # Go 单元测试
node --test test.mjs  # 前端单元测试（纯函数 + HTML 构造器 + api 打桩）
```

### 打包与发布

```bash
build.bat        # 生成 bin\huashan-query-v<VERSION>.exe（版本号注入自 VERSION 文件）
build-test.bat   # 生成受限测试版：最多查询 20 次或运行 20 分钟
release.bat      # 一键发布：构建 → 推 GitHub+Gitee → 建发行版并上传 exe → 更新 latest.json
```

发布物为 `bin/` 下的单个 exe（已被 `.gitignore` 忽略，不入库）。`release.bat` 会自动把它作为发行版附件上传并生成下载直链；发布信息读取自未入库的 `deploy-token.txt`（Gitee 令牌）与 `deploy-url.txt`（更新清单地址）。

## 架构

**依赖方向**（单向无环）：`main → server → player → huashan → token → wechat → leveldb`；`logx` 为叶子工具。
**前端模块**：`main → {ui, api, compare, options}`；`ui → {format, api, compare, view}`；`compare → {format, api, view}`；`api`（只连本地）与 `format`、`view` 无外部依赖。

**职责边界**：Go 负责所有**重计算**——leveldb 解析、令牌聚合校验、并发分页拉取、聚合 / 角色分解 / 候选 / 按作用域筛选、内存缓存；前端只做**轻活**——中文标签、百分比 / “—” 格式化、赛区名 / 荣誉文案，以及逐场表的排序 / 快捷筛选 / 分页与单局弹层排版。作用域变化才请求后端（命中缓存即时返回），表内交互只在本地重渲染。

```
main.go                      入口：装配 令牌源 → 客户端 → 服务 → 开浏览器；心跳驱动生命周期
internal/
  leveldb/                   纯 leveldb 解析（SSTable / WAL / Snappy），与业务无关
  wechat/                    微信目录发现 + 从本地存储取候选令牌（实现 token.Source）
  token/                     令牌聚合 / 去重 / 排序 + 联网校验 + 缓存，给出当前有效令牌
  huashan/                   官方接口传输层：注入令牌、401 刷新重试、分页并发拉取、错误归一
  player/                    计算层：解析 / 聚合 / 候选 / 单局复盘 + 选手级 LRU 内存缓存，产出数值化 DetailView
  server/                    本地内存服务：内嵌 web/ 静态资源 + 本地 JSON API（/api/*，只依赖 player）
    web/                     唯一前端（embed.FS 打进 exe，磁盘不落文件）
      index.html             页面骨架
      styles.css             全部样式
      js/format.js           展示层纯函数：转义 / 配色 / 字段中文标签 / 赛区名 / 单局技能投票文案 + 共享表格原语（键值取值·列排序）
      js/api.js              网络薄壳：只连本地 /api/*，解析错误、维护令牌有效期与版本号
      js/ui.js               单人详情：取模型 + 标签格式化 + 逐场表本地筛选 / 排序 / 分页 + 单局弹层排版
      js/compare.js          多人对比：对比篮 + 对比表（按阵营 / 按身份，排序 / 聚焦 / 后台预热）
      js/view.js             当前视图归属（search / detail / compare），避免异步回调互相覆盖 #detail
      js/options.js          右上角 ⚙ 选项菜单：主题 / 使用说明 / 分享 / 反馈 / 版本号
      js/main.js             引导：暴露内联处理器、启动取会话信息
  logx/                      跨层错误日志（仅错误、英文、带调用栈）
test.mjs                     前端单测（node --test，直接 import web/js 各模块）
VERSION / CHANGELOG.md       版本号与更新日志
build.bat / build-test.bat   一键打包 / 打包受限测试版
```

**技术栈**：Go 标准库（`net/http` + `embed.FS`，无框架、无第三方依赖）+ 原生 ES Modules 前端（无构建步骤）。

## 隐私与安全

- 登录令牌**只在本机内存中使用**，不会写入磁盘；普通查询由 Go 侧注入请求头，只有手动粘贴或用户明确点击右上角“复制 Token”时才会进入页面内存。
- 手动输入会先通过华山官方接口校验；本地 Token 接口禁用缓存、拒绝跨站读取与表单写入，程序不把令牌上传给华山官方以外的第三方。
- Token 等同短期登录凭证。复制后只应发给信任的人；对方在有效期内可读取该账号有权查看的数据，即使本程序本身没有写操作也不能视为零风险。
- 令牌文件、日志、构建产物均已在 `.gitignore` 中排除，不会入库。
- 前端 JS 在浏览器可被 F12 查看；普通查询请求 / 响应不含令牌，但手动粘贴与主动复制时的本地 `/api/token` 请求可被本机开发者工具观察。

## 限制

- 华山普通用户仍需先通过**微信**获得登录态（无桌面 / 扫码入口）；程序可从本机微信存储自动读取，也可临时使用他人主动分享的有效 Token。
- 仅支持 Windows（依赖电脑版微信的本地存储结构）。
- 数据为打开程序时的一次性快照，不自动刷新。
