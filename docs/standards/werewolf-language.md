# 狼人杀显示术语

本规范用于界面、提示、帮助、更新说明和展示层测试。术语以《华山论剑赛事手册》和项目现有牌局数据为依据。

## 表达原则

- 牌局信息使用狼人杀玩家熟悉的概念和动作。
- 同一概念在所有显示位置使用同一个名称。
- 身份名称使用牌局数据和赛事手册中的正式名称。
- 技能使用身份对应的动作词，紧凑视图使用约定的单字简称。
- 事件描述呈现牌局事实、行动方、目标、时间和结果。

## 基础概念

- 比赛中的一场游戏称为“对局”或“牌局”，详细记录称为“单局复盘”。
- 玩家在一场牌局中的牌称为“身份”。
- 阵营使用“好人”和“狼人”；赛果使用“好人胜”和“狼人胜”。
- 花名册按“狼队”“神职”“平民”展示。
- 玩家位置使用“座位”或“N号”。
- 牌局进程使用“第 N 天”和“第 N 夜”；紧凑记录使用“D1”“D2”等天数标记。
- 离开当前牌局的状态使用“出局”，仍在牌局中的状态使用“存活”。
- 身份构成使用“版型”，同场身份集合使用“阵容”。

## 身份归类

### 狼人阵营

狼、狼王、狼美人、隐狼、石像鬼、血月使徒、恶狼骑士、机械狼、梦魇、怪盗狼王。

“白狼王”不在现行赛事手册的版型和结算规则中，仅用于展示历史赛季的牌局数据。

### 神职

预言家、女巫、猎人、白痴、守卫、骑士、守墓人、摄梦人、猎魔人、警犬、熊、侦探。

### 平民

平民。

## 技能动作

- 狼人：刀；完整事件名称使用“狼刀”。
- 预言家：查验；紧凑技能行使用“验”。
- 女巫：救、毒。
- 猎人：开枪、带走；紧凑技能行使用“带”。
- 守卫：守护；紧凑技能行使用“守”。
- 侦探：翻牌。
- 警犬：查验、撕咬。
- 梦魇：恐惧。
- 狼美人：魅惑、连人。
- 猎魔人：狩猎、反噬。
- 石像鬼：查验、猎杀。
- 骑士：决斗。
- 摄梦人：摄梦；紧凑技能行使用“摄”。
- 怪盗狼王：顶盾。
- 狼王：带人。
- 狼人阵营主动离场：自爆。

### 手册用词与显示用词的对应

规则速查引用手册原文时使用手册用词，牌局记录和统计沿用既有显示用词，两者互为同义词并同时作为搜索关键词。

- 狼美人技能结果：手册用“殉情”，牌局记录显示“狼美人连人”。
- 骑士决斗好人后自己出局：手册用“断剑”，牌局记录显示为骑士出局。
- 石像鬼在三名狼人出局后的击杀：手册用“带刀”，牌局记录显示“石像鬼猎杀”。

## 警徽与投票

- 警徽流程使用“警徽竞选”“警徽投票”“当选”“警徽生效”“警徽转移”。
- 白天票型使用“投票”“警长票”“弃票”。
- 票型结果使用“放逐”或“平安白天”。
- 投票目标按“N号 选手名·身份”展示。
- 警长票使用星标并说明“警长 1.5 票”。
- 与预言家保持一致的分票称为“外置位投票”。
- 平票后的再次发言与投票称为“PK 台”。

## 评选与计分

- 阵营评选结果使用“MVP”“尽力”“背锅”。
- 投票和技能造成的出局结果计入“人命”，票型结算结果计入“投票分”，身份技能结算结果计入“身份附加分”。
- 达成额外获胜条件的加分使用“彩蛋”。
- 狼人跳预言家使用“悍跳”，摸到狼人身份使用“摸狼”。
- 狼人投票的立场使用“冲锋票”“倒钩票”“未投票”。
- 好人替他人承受狼刀的结果使用“挡刀”。
- 摄梦人使梦游者免疫女巫毒药的结果使用“挡毒”，连续两晚摄同一名选手使用“双摄”。
- 怪盗狼王的免疫状态使用“顶盾”。
- 狼人在夜间直接宣告结束牌局的操作使用“拍刀”，刀型不统一的结果使用“空刀”或“掰刀”。
- 血月使徒吃下毒药或狩猎的结果使用“吞毒”“吞猎”。

## 违规与纪律

- 违规类别使用“发言违规”“行为违规”“重大失误”。
- 取消当局比赛资格使用“DQ”。
- 当局违规导致的扣分使用“违规扣分”，不归属具体对局的赛事级扣分使用“赛外违规扣分”。

## 赛事数据

- 赛事范围使用“赛区”“赛季”“轮次”“门派”。
- 对局表现使用“场次”“场均分”“胜率”“投狼率”“站对边率”。
- 赛事标记使用“MVP”“尽力”“背锅”“违规扣分”。
- 淘汰赛沿用前序成绩的起始分使用“带入积分”。
