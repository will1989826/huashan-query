# 选手数据分析知识库

本知识库用于解释华山狼人杀选手统计与复盘数据。它保存可复用的判断框架，不保存具体选手的阶段性结论，也不替代赛事规则。

## 信息边界

按以下优先级处理信息冲突：

1. 《华山论剑赛事手册》及项目整理的官方规则；
2. 官方接口返回的原始数据；
3. 由代码复算、可重复得到的派生统计；
4. 本知识库中的领域解释；
5. 针对单个选手形成、仍待验证的假设。

第 2 层的官方选手汇总（T0）与第 3 层的自算派生统计是两个不同来源：投狼率、站对边率等既有官方 T0 口径，也有本项目用单局详情（T2 form2）全量重建、可复算的自算口径。二者定义与分母可能不同，分别报告、不合并。自算派生统计继承单局重建的已知不确定性（见 [`evidence-method.md`](evidence-method.md) 的“重建不确定性”）。

狼人杀显示用语以 [`docs/standards/werewolf-language.md`](../../standards/werewolf-language.md) 为准。计分、评选优先级和身份规则以 [`internal/server/web/js/rules-data.js`](../../../internal/server/web/js/rules-data.js) 中对应的官方资料为准。知识库只说明如何使用这些事实，不复制整套规则。

## 内容导航

- [`evidence-method.md`](evidence-method.md)：事实与假设的三档线、落差模型、数据层级、对照基线、切片与时效描述符、证据强度和结论格式。
- [`metrics.md`](metrics.md)：场次、得分、胜率、评选、人命、投票、技能、主导（警长）和狼人行动指标。
- [`survival.md`](survival.md)：好人与狼人存活率的条件化解释、验证组合和禁止推断。
- [`player-traits.md`](player-traits.md)：选手特性维度（好人／狼人／跨角色／读感／通用），每条按数据判据描述、不拼成角色。

分析一个完整的选手画像时，先读证据方法，再读指标与存活率，最后读特性维度。只解释单个指标时，可以从指标页进入，但仍须遵守证据方法中的基线和置信度要求。

## 职责划分

- 能由输入唯一决定的清洗、去重、分组、计数和比率计算，放在分析代码中。
- 指标含义、混杂因素、竞争解释、必要证据和反证，放在本知识库中。
- 何时触发分析、调用什么工具、读取哪些资料及如何组织交付，放在 skill 中。
- 具体选手、具体时期的结论属于分析报告，不进入知识库。

一句话原则：确定性计算放代码，领域判断放知识库，任务编排放 skill。

## 维护规则

- 新增官方字段或身份时，先核对官方定义，再更新术语或规则资料，最后补充本知识库的解释边界。
- 新增特性维度时，写明数据判据、读出的结论和最低数据层级。
- 不能稳定复算的判断不得包装成指标；只能作为解释或待验证假设。
- 不用个别选手或单局故事直接建立通用规律。需要用跨选手、跨赛季数据验证的新经验，应记录适用条件。
- 规则、接口范围或计分口径变化后，重新检查跨赛季比较是否仍成立。
