# 通用能力标签

本页定义如何把可复算指标转换成跨玩家一致的标签。标签用于概括某个独立维度，不把多个维度拼成角色或整体玩法，也不替代原始值、分子、分母和证据说明。

## 两类产物

- **个人分析**：综合全量生涯、自然年、最近 N 场、身份、版型、对手和队友环境，报告数据支持的独立特性与水平。
- **通用标签**：对一个定义稳定的指标，在可比人群中计算分布区间，再给每名合格玩家赋予同口径标签。

个人分析可以引用多个标签作为证据，但主要结论仍须遵守证据方法：至少两个非重复信号，并给出竞争解释或缺失证据。

## 标签类型

- **能力标签**：直接对应个人可归属行为，如公开狼前投狼、站边、个人技能命中、悍跳收益或后期主动贡献。
- **结果标签**：胜率、MVP、尽力、背锅和结果超预期等，受队友与对手共同影响。
- **结构标签**：最终存活、夜死、白天放逐、屠边环境和身份构成，不单独解释为能力。
- **倾向标签**：冲锋、倒钩、悍跳、自爆等选择频率，描述行为分布，不直接表示强弱。

标签必须保存类型。结果、结构和倾向标签不得在展示层改名为能力标签。

## 可比人群

先建立与指标职责一致的参照组：

- 好人与狼人始终分开；
- 身份机制显著影响指标时，按平民、普通神职、高频具体身份、普通狼和特殊狼拆分；
- 规则或版型变化会改变机会时，按规则时期或版型组拆分；
- 生涯、自然年和最近 N 场使用各自同切片人群，不交叉训练阈值；
- 赛区或赛事类型差异足够大时，优先使用同赛区、同赛事类型基线，并保留全体基线作补充。

参照组不足时逐级回退到更宽但仍同阵营的组，并记录实际使用的组。不得为凑样本跨阵营合并。

## 分母与收缩

每个指标定义自己的机会分母。技能率用真实技能事件，站边率只用有效对跳日，投票率只用符合阶段定义的有效投票，不能借用阵营总场次。

- 分母为 `0–9` 时只显示原始事实和“样本不足”，不参与标签阈值训练；
- 分母达到最低要求后，用同组基线作经验收缩，避免少量样本的 `0%` 或 `100%` 主导排序；
- 收缩前原值、收缩后估计、先验组和等效先验样本量全部保留；
- 置信度继续使用证据方法的 `0–9 / 10–29 / 30–79 / 80+` 披露，不把收缩当成提高真实样本量。

推荐的二项率收缩形式为：

```text
smoothed_rate = (numerator + baseline_rate * prior_weight) / (denominator + prior_weight)
```

`prior_weight` 是版本化模型参数，需用历史校准或稳定性验证选择，不因单个玩家调整。

## 大样本区间

阈值来自当前分析版本中合格参照人群的收缩后分布，而不是手写绝对百分比。默认五档使用：

| 百分位 | 通用档位 |
|---:|---|
| `< P10` | 显著偏低 |
| `P10–P30` | 偏低 |
| `P30–P70` | 中位区间 |
| `P70–P90` | 偏高 |
| `>= P90` | 显著偏高 |

具体显示名称由指标方向决定。例如投狼命中可以显示“找狼投票命中偏高”，背锅率只能显示“背锅率偏高”，冲锋占比显示“冲锋倾向偏高”。档位边界、参照人数、数据截止日和分析版本必须可查询。

当合格参照玩家少于 30 人时，不生成五档标签；可以回退到更宽参照组，仍不足则仅显示原值和样本说明。

## 稳定性与特色

一个标签成为个人“特色”，至少满足：

- 达到 `P10` 以下或 `P90` 以上，或在领域上有明确意义的组合关系；
- 有效分母不少于 10，并显示对应置信度；
- 生涯与自然年或最近 N 场方向不发生无法解释的反转；发生反转时改报“近期变化”；
- 不是由单一身份、单一版型或单一固定阵容完全驱动，除非标签本身明确限定该范围。

结果标签不能单独成为个人能力特色。例：高胜率还需场均、败局贡献、局内执行或对手校正中的另一项独立证据。

## 版本与更新

每次构建保存：指标定义版本、参照组、合格人数、分位阈值、收缩参数、源数据截止点和分析运行 ID。

- 新数据加入后，重新计算受影响玩家的指标，并重算全体阈值和标签；
- 旧局修正后，先按对局环境规则重算时间相关指标，再生成阈值；
- 标签变化要能区分“本人数据变化”“参照人群变化”“指标定义变化”；
- 不覆盖历史阈值元数据，以便解释不同分析版本的标签差异。

## 禁止事项

- 不隐藏原值、分子和分母，只显示标签；
- 不用当前官方 T0 黑盒百分比训练历史 T2 能力标签；
- 不把低样本极值评为顶级或垫底；
- 不把同组百分位称为全体绝对排名；
- 不用多个机械耦合字段堆叠出虚假的综合高分；
- 没有 T3 时，不生成发言内容、夜间指挥或心理动机标签。
