# 狼人阵营表现模式

以下模式用于组织证据，不是玩家的固定属性。投票、狼刀和胜率含有较强团队成分，应优先寻找能够归到个人的行为与收益。

## 正面悍跳核心

**必要证据**：足量悍跳样本；成功率、警徽或真神出局收益；悍跳局的人命、得分或狼队胜率高于合适基线。

**反证**：成功次数很少；高狼人胜率主要来自未悍跳局；悍跳后立即出局且没有换取警徽、真神或轮次。

## 深水与后置经营

**必要证据**：普通狼而非仅特殊狼的 D3+ 存活较高；较少悍跳和无收益早出；后期能通过投票、人命、抗推或存活推进胜局。

**反证**：存活只是狼人获胜的机械结果；队友完成全部控场；本人后期没有可见贡献。缺少 T2 时只能称“高存活型”。

## 冲锋狼

**必要证据**：在悍跳结构中通过持续投票、警徽票或可核实的发言支持狼队友，并换得警徽、放逐好人或轮次优势。

**反证**：只是投了好人但未帮助悍跳；冲锋使狼队同时暴露；缺少票序、发言和实际收益。

## 有效倒钩狼

**必要证据**：早期有成本地切割狼队友，借此取得可信身份，并在后续关键轮次推动好人出局或存活至残局。

**反证**：队友已裸或必出时的无成本投票；切割没有换得身份；切割直接损害狼队轮次。投队友本身不等于高质量倒钩。

## 前置工作或牺牲位

**必要证据**：D1/D2 高频出局，同时完成悍跳、自爆、冲锋或特殊技能任务，并换得人命、警徽、真神出局或团队轮次收益。

**反证**：早出局但没有可量化收益，同时个人低得分、低评选且团队胜率低。不能把所有低存活狼人美化为牺牲位。

## 夜间战术贡献

**必要证据**：可归属个人的特殊狼技能、自刀收益，或有可信来源记录其提刀。普通狼刀神率只能描述该玩家所在狼队的刀型结果。

**反证**：只有全队统一狼刀记录，没有夜间讨论或个人建议来源。此时不能证明个人抿神或刀法能力。

## 特殊狼专长

**必要证据**：多个特殊狼身份，或足量单一身份，持续优于该玩家普通狼；相应技能、人命或结算能够解释收益来源。

**反证**：一两场全胜；优势完全来自该特殊身份所在版型的整体狼胜率；普通狼样本太少，无法形成对照。

## 跨模式表现结构

### 稳定输出

场均、胜率、评选、人命及职责完成度在多个赛季、普通/特殊狼和近期切片中方向一致。大样本不自动等于稳定。

### 高上限、高波动

高 MVP 同时伴随高尽力或背锅、得分方差大、身份或职责差异明显。没有逐场分布时，不对波动原因下定论。

### 团队结果型

狼人胜率高但场均、人命和个人任务指标普通，可能是团队适配或稳定分工。由于胜率和存活机械相关，不能再用高存活作为第二条个人能力证据。

### 败局贡献型

狼人胜率普通或偏低，但败局得分、尽力、人命或任务收益较好，支持逆风贡献，不代表团队协同一定优秀。

## 禁止的捷径

- 高狼人存活率 = 深水狼；
- 低存活 + 高狼人胜率 = 牺牲位；
- 高刀神率 = 个人抿神强；
- 投狼队友 = 有效倒钩；
- 投好人 = 有效冲锋；
- 悍跳胜率高 = 悍跳过程一定强；
- 特殊狼高分 = 普通狼也强。

这些只能形成待验证假设，必须补充职责、时点、收益、身份和反证。
