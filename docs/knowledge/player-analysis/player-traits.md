# 选手特性维度

画像是一组由数据支持的独立特性，按数据支持哪条就报哪条，不拼成角色，也不合成整体玩法。每条给出数据判据和读出的结论；特性需跨局重复才成立（置信度见 [`evidence-method.md`](evidence-method.md)）。投票、站边、存活、技能命中均用自算口径。

## 好人

- **找狼命中率**（投狼 ＋ 验/毒/带/翻 中狼，合一）：识别狼的能力。技能命中与投票同理，用错等于投错狼，合并计算，各带事件分母。
- **站对边率**（对跳日跟真预言家的比例）：认真预言家、跟对主线的能力。高站对边＋高找狼为独立且跟对；高找狼＋低站对边为能抓具体狼而主线易跟错。
- **站对边却被白天放逐的比例**：判断对却没被好人取信。
- **站错边却活到终局的比例**：判断错仍逃过清算，跨局偏高为发言能圆、被包容。
- **胜局投票正确率**：低为靠队友赢。
- **败局投票正确率**：高为个人判断到位、队友没兜住。
- **投票正确率高而存活率低**：能找狼、发言不被认可，常被投出。
- **好人胜局／长局的 D3+ 存活率与 D3+ 投票、人命贡献**：残局产出能力。
- **平民 D2+ 夜死率**：被狼当威胁（狼把本该给神的刀用在他身上）。

## 狼

- **悍跳成功率、真预言家清除率**（夜刀或白天抗推）：身份竞争与清除最高价值目标的能力。
- **冲锋后存活时长**（悍跳狼出局后仍存活的比例）：暴露立场仍能取信为发言好；悍跳狼在世期的存活由悍跳狼 carry，不计入。
- **倒钩后存活时长**：D2 起倒钩被视为投对，活得久为取信成功，被白天清掉为取信失败。
- **普通狼 D3+ 存活率与后期投票、人命贡献**：后期推进胜局的能力（存活天数口径）。
- **D1/D2 早出局，且伴随悍跳/自爆/抗推真预言家，且换到警徽或真神出局或轮次的比例**：前置贡献（报相关性，不认个人主动性）。
- **自刀**：D1 主动为发言不自信（靠银水好人面）；D2+ 悍跳狼为战术误导辨预言家；女巫救成即银水成型。
- **团队夜刀误判率／故意屠民率**（相位化，团队级）：该玩家所在狼队的抿神质量，不归个人。
- **梦魇恐惧对神率、狼美人魅惑对神率**：可归个人的抿神（每晚个人选目标，施给神牌价值最高）。

## 跨角色（需好人局与狼局样本）

- **拿好人的找狼命中／存活 与 拿狼的存活对比**：拿好人强而拿狼死得快为人狼不统一。
- **拿好人强，且拿狼靠倒钩才活**：只能装好人求生。
- **拿好人强，且拿狼冲锋也能活久**：两面都强，扛得住暴露的狼位。
- **当真预言家推死悍跳狼的比例 与 当悍跳狼推死真预言家的比例**：两边都高为对跳博弈发言真强；只赢真预言家一边为钢铁、不擅悍跳。

## 读感

- **被验率，及被验为狼（查杀）／为好人（金水）的比例**：被预言家选为查验对象的频率反映嫌疑度与存在感；作狼易被查杀为狼相重，作好人常被发金水为好人相。

## 通用

- **生涯／自然年／最近 N 场的方向一致性**：一致为稳定，分化为上升或下滑。
- **MVP 率与得分方差**：高 MVP ＋ 高方差为上限高、波动大。
- **胜率与场均的落差**：高胜率低场均为团队兑现，高场均为个人附加分强，败局得分与尽力高为逆风贡献。

---

每条特性独立报告，不合成角色或玩法画像。跨角色与读感属画像与赛前准备用途，不作对局中的确定性数据库发言。
