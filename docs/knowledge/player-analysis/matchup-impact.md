# 对局环境与交互影响

本页定义如何使用 T1/T2 历史数据分析赛前阵容强度、比赛难度、团队协同和玩家之间的关联。它不把团队赛果直接归功于个人，也不使用目标对局之后的数据解释目标对局。

## 证据边界

- 赛果、阵容、身份、投票、技能、出局和存活是可复算事实。
- 赛前强度、预计胜率和组合效果是基于历史事实的统计估计，不是官方指标。
- 同队效果和对位效果是赛程条件下的关联，不证明某位玩家导致另一位玩家变强或变弱。
- 没有 T3 时，不推断具体发言内容、夜间指挥、团队提议归属或心理动机。
- 普通狼刀属于团队动作；特殊狼独立发动的技能可以按知识库既有规则归个人。

## 时间边界与数据泄漏

评价一场对局时，只能使用该局开始前已经发生的对局。目标局及其后的数据不得进入该局的赛前能力、对手强度或预计胜率。

- 对局按 `play_date` 排序；同日缺少准确开赛时间时，以赛事轮次、`game_id` 作稳定次序，并披露同日顺序是近似值。
- 首次出现或历史样本不足的玩家向同阵营、同赛季基线收缩，不能用其未来生涯数据补足。
- 官方 T0 生涯汇总只有抓取时的当前快照，不用于回填历史赛前强度。
- 新增晚于现有截止点的对局可以延续历史快照；补录或修正旧局时，从最早变更局开始重算后续快照。

## 赛前能力

好人与狼人职责不同，分别建立能力记录，不生成跨阵营的原始平均值。

### 好人能力输入

- 公开狼前、首轮和关键放逐轮的投狼记录；
- 对跳日站边、警徽投票和后续纠错；
- 验狼、毒狼、带狼、翻狼等个人技能命中；
- 胜局与败局分别的投票正确率；
- 按身份、屠边方向和牌局长度条件化的 D3+ 存活与贡献。

### 狼人能力输入

- 悍跳获得警徽、推动真预言家出局和取得轮次的记录；
- 冲锋、倒钩及悍跳狼出局后的存活和后续收益；
- 普通狼 D3+ 存活与后期推动好人出局；
- D1/D2 早出局换到警徽、真神或轮次的前置收益；
- 梦魇恐惧、狼美人魅惑等可归个人的技能目标质量。

团队夜刀质量可以作为该狼队所处环境的描述量，但不进入某名普通狼的个人能力。

## 比赛难度与结果价值

一场对局至少拆成以下字段，默认不合成单一“含金量分”：

- **对手强度**：对方阵营所有玩家在赛前的同阵营能力聚合；
- **队友支持**：本方其他玩家在赛前的同阵营能力聚合；
- **预计胜率**：控制赛季、版型、身份构成和规则时期后的本阵营获胜概率；
- **结果超预期**：实际结果减预计胜率，低预计胜率下获胜为较高正残差；
- **局内执行**：目标玩家本局可归个人的投票、技能、评选、出局阶段和后期贡献；
- **覆盖与置信度**：赛前历史样本、T2 重建覆盖率和模型版本。

“赢下强敌”只需要对手强度和赛果支持；“个人带队赢下强敌”还必须有独立的局内执行证据。团队获胜与个人存活、MVP 与得分等机械耦合信号不得重复当作多份证据。

## 好人团队协同

按天计算，并区分公开信息形成前后：

- 投票集中度、主票占比、分票目标数和弃票率；
- 投向狼人的集中度与投向好人的错误一致性；
- 对跳日站边分裂程度；
- D1 站错后在 D2/D3 的纠错人数和纠错速度；
- 关键放逐轮中正确票与错误票的分布。

高度一致不等于高质量。正确一致、错误一致和意见碎片化必须分别报告。绑定票形成后的高度一致主要反映票权结构，不能等同于独立判断。

## 同队与对位效果

- **同队效果**：两名玩家同阵营时的实际结果或局内表现，相对赛前模型期望的残差；好人搭档与狼人搭档分开。
- **对位效果**：两名玩家分属不同阵营时的结果残差；按双方实际阵营方向保存。
- **行为协同**：好人组合的正确投票一致、纠错和残局贡献，或狼人组合的真预言家清除、轮次收益等客观共同结果。

组合统计必须显示共同场次、时间范围、版型分布和收缩后估计。固定门派、固定赛区、连续赛程和常见搭档会形成聚类，是所有组合结论的竞争解释。

## 样本与表达

沿用证据方法的分母披露：`0–9` 仅作线索，`10–29` 低置信，`30–79` 中等置信，`80+` 较高置信。组合样本稀疏时向对应阵营基线收缩；未经收缩的小样本极值不进入排序结论。

推荐表达：

- “在赛前模型中属于较低预期下获胜”；
- “与该搭档同队时结果高于阵容预期，但样本较少”；
- “面对高找狼历史表现的好人阵容仍获胜”；
- “该组好人在公开信息形成前票型较分散”。

禁止表达：

- “证明某玩家带飞／拖累另一人”；
- “这名玩家一定克制另一名玩家”；
- “胜利含金量高，所以本人发挥一定好”；
- 用抓取时的官方生涯汇总倒推历史每一局的赛前水平。

## 新数据与修正

每次分析运行记录源数据截止点、内容哈希、知识库版本和算法版本。

- 新局只影响新局事实、当前聚合及其后的时间快照；
- 旧局内容变化时，重建该局事实，并从最早变化日期重算后续赛前快照；
- 删除或范围变化默认触发全量重建；
- 新结果全部生成成功后才切换为最新版本，失败时继续保留上一版；
- 任一结果都能通过 `analysis_run_id` 和 `game_id` 回溯到源数据与计算版本。
