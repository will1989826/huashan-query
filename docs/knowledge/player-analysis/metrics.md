# 指标解释

本页给出每个指标描述什么、由什么决定、怎么读。字段精确计分以官方规则资料为准。投狼率、站对边率等有官方 T0 汇总与自算 T2 两个口径，定义与分母不同，分别报告（见 [`evidence-method.md`](evidence-method.md)）。

## 场次、得分与胜率

### 场次
场次反映结果稳定性与参赛环境跨度。老选手的大样本混合多个年代、赛区、对手、门派、版型和规则版本；新选手的小样本受单次赛事放大。

### 场均分与总分
场均分是阵营基础分、评选、人命、投票、身份附加分和违规扣分的综合结果，在同阵营、相近计分版本内比较。高场均＋高胜率多来自阵营基础分，结合人命、评选和败局得分读；高场均＋普通胜率支持个人附加分能力；高胜率＋普通场均支持团队结果兑现。总分反映参赛量。

### 场均分与胜率的落差（必须分阵营读）
计分规则对两个阵营不对称，所以同一条"场均分 × 胜率"落差在好人面和狼人面含义不同，画像按阵营分别给读法。

规则不对称的三处来源：背锅只在狼人获胜时扣好人 1 分，**狼人自己永远不背锅**；投票分在好人获胜时只按错票扣分、好人失败时才按对票加分（上限 3 分）；MVP 只从获胜阵营产生、尽力只从落败阵营产生。

实测（本地库 4779 人，各阵营场次 ≥30，好人 n=1170、狼人 n=507；**在同一胜率三分带内**比高场均与低场均两组，排除胜率本身的干扰）：

| 落差 | 好人 | 狼人 |
|---|---|---|
| 同胜率下场均分高低的**主要来源** | 人命（+0.17~0.19/场，接近翻倍）、投狼率（+6 个百分点）、女巫毒狼率（+10 个百分点） | MVP 率（+0.047~0.071）、悍跳成功率（+4.7~6.4 个百分点） |
| 同胜率下**几乎无关**的项 | 存活率（只差 0.5~1.2 个百分点） | 尽力率（只差 0.005~0.014） |
| 胜率高＋场均低 | 投狼率 52.5% 对 59.2%、人命 0.10 对 0.28、背锅率 0.093 对 0.068，存活率两边相同（64.4% 对 65.2%）→ **投不中狼、背锅偏多，赢多靠队伍带** | MVP 率 0.119 对 0.207、悍跳成功率 22.9% 对 30.8% → **狼队赢时几乎没有扣分点，分低来自 MVP 与悍跳产出少** |
| 场均高＋胜率低 | 投狼率 60.4% 对 54.0%、女巫毒狼率 63.7% 对 51.2%、人命 0.32 对 0.12、尽力率 0.115 对 0.087 → **败局里投对票多、技能常杀狼、也拿尽力，个人产出没换成胜局** | MVP 率 0.243 对 0.145、悍跳成功率 34.0% 对 23.9%、人命 0.68 对 0.51，尽力率只差 0.009 → **个人产出高但狼队没赢**；不是"靠拿尽力"，狼人尽力按规则近似机械发放（狼队依次出局时悍跳狼尽力、无悍跳时最后一名狼尽力），方差很小 |

两条推论：好人场均分在同胜率下几乎只由"投中狼＋技能杀狼"的人命决定，存活率贡献可以忽略；狼人场均分在同胜率下主要看 MVP 与悍跳，尽力率不具备区分度，不要用尽力解释狼人的场均落差。

### 胜率
胜率衡量团队结果兑现，受同伴、对手、版型和赛区强度影响。近期胜率变化结合阵营、身份和对手构成读。

## 评选与人命

### MVP、尽力与背锅
MVP 支持胜局中的相对贡献，尽力支持败局中的相对贡献，两者都受同阵营队友表现和官方评选顺序影响；背锅是负面结果线索，结合身份、人命、投票和违规读。次数换算成对应阵营或身份场次的比率并显示分母。

### 人命值
人命反映投票和技能造成的出局结果，受主导、参与和技能结算规则影响。预言家查验、女巫毒、警长归票和狼人悍跳产生人命的路径不同，结合身份和具体行为拆分。

## 好人判断指标

### 投狼率
投狼率描述投票目标阵营。自算口径拆首轮、关键放逐轮、公开狼后跟票和改票，优先用分轮结果——首轮独立投中与公开狼后的跟票价值不同。

### 站对边率
站对边率按选手逐局计算，不要求存在悍跳狼。每局只取首次普通白天投票（排除警徽票，可发生在任意天）。非预言家的好人选手在该次投票时仍存活并有投票记录，且真预言家仍存活时，该局记为这名选手的一次站边机会；存活但弃票也记机会、但不算站对。真预言家本人不计入。

通常，选手与真预言家投向同一目标即站对；真预言家投给好人 B、B 自己投给狼人时，B 也算站对。若真预言家在第一天夜里被刀且未被救、被女巫毒或因同守同救出局，而牌局仍有普通投票，则仍记其他存活好人的站边机会，投给任意狼人即站对。真预言家在第二天或更晚的夜里出局后才出现首次普通投票时，不计站边机会。站对边率为站对局数除以站边机会局数。与投狼率联用（投狼率＝独立找狼，站对边率＝站边）：

| 投狼率 | 站对边率 | 读法 |
|---|---|---|
| 高 | 高 | 独立找狼和站边都稳，进一步看是否在关键轮次、是否主导 |
| 高 | 低 | 能独立找狼，站边偏跟错或后置修正，看首次站边、改票和票序 |
| 低 | 高 | 站边跟对，独立找狼或外置位处理较弱，看是否主要跟随真预言家 |
| 低 | 低 | 独立找狼和站边都偏低，看身份、赛季和版型偏差 |

站对边却被白天投票放逐，支持取信／发言问题（落差模型，见 [`evidence-method.md`](evidence-method.md)），不断言具体差在哪。

### 警徽投对率
警徽竞选投票（`vote_jinhui`）投向真预言家等好人候选为投对，补充信息较少的早期判断。候选结构、退水、自爆和投票资格改变分母，与白天持续站边数据分开看。

> 方向已实测校正：官方 `haoren_json.tjh_pct` 与自算「警徽票投中好人占比」相关 +0.931、与「投中狼人占比」相关 −0.931，均值 60.2% 对 60.4%，即**投中好人为投对**（旧文档误写为“投向狼为投对”）。因此本项与自算的 `badge_seer_hit_rate`（对跳局里警徽票投给真预言家）方向一致，只是分母更宽：官方算全部警徽票，自算只算对跳局。

### 身份技能率
女巫毒狼率、猎人带狼率、预言家验狼率、侦探翻狼率按目标阵营判定，反映技能命中。展示事件分母，结合对应身份场次、场均和胜率读；小样本的 0% 或 100% 作线索。

## 狼人行动指标

### 悍跳次数与成功率
悍跳成功率支持正面身份竞争能力，结合起跳身份、警徽归属、真神出局、本人出局阶段和狼队赛果读。未悍跳可能来自连续摸狼强制悍跳规则、团队分工或特殊身份。悍跳狼在世期靠绑票速推获胜时，队内其他狼的存活由悍跳狼 carry，计为悍跳狼取信好（见落差模型）。

### 刀神率
刀是团队动作，个人页刀神率描述该玩家所在狼队的夜间刀目标质量（团队抿神），归团队。特殊狼的个人技能杀（石像鬼带刀／狼美人连人／狼王带人）归个人，另算。

- 按**刀的目标角色**算：刀向神即抿神对，被守／被救成平安夜同样算对；掰刀／空刀（狼号不统一，或梦魇封狼）单列。
- **刀目标价值＝剩余持续威胁，版型感知**：N1 女巫最高（解药能废首刀，毒药持续）；有预言家版型 N2+ 预言家最高（每晚验人）；持续技能神（女巫、警犬、守卫、摄梦人、守墓人、猎魔人等）为高价值；一次性技能神发动后为低价值目标（如侦探翻牌后，刀他接近刀民）。
- **刀民的判定用结果**：屠民胜（狼赢且有神职存活，如预言家活着）时，全局刀民为**故意**（屠民线）；狼本意屠神、刀错民、且该局非屠民胜时为**误判**。屠神仍是主线时的刀民（首夜刀民、白天推掉预言家后刀民、预言家在场却刀民）计误判；此前有平民被抗推或死于神技作故意的早期佐证。
- **头号信号是真预言家的清除**：夜刀预言家或白天抗推掉预言家、清除时点，很大程度定狼队胜负；投票抗推真预言家可半归个人。狼队计划白天抗推预言家、或指望女巫毒预言家时不夜刀预言家也对，用结果反查（预言家最终死于抗推或女巫毒则成立）。

### 自刀
自刀是取信工具，按天与角色分读：

- **D1 主动自刀**：靠银水好人面拐杖，支持发言不自信（偏负面）。
- **D2+ 悍跳狼自刀**：误导好人辨认真预言家，支持战术操作（偏正面）。
- 其他自刀逐例看，多为骗药消耗女巫解药。

女巫解药救了自刀目标即骗药成功、银水成型，其后续存活／取信按落差模型读。

官方 `langren_json.zidao_num`（画像里的「自刀率」）无法按天拆分，实测它与自算自刀的关系是：全部自刀尝试里 **84% 发生在第一天**（1759/2105 次，13728 局重建），逐人比对下 `zidao_num` 与「第一天自刀次数」相关 +0.943、70.6% 完全相等，与「全部天数自刀次数」相关 +0.968、80.3% 完全相等；总次数 801 落在第一天口径（746）与全口径（902）之间。因为自刀本身高度集中在首夜，两种口径无法干净区分，所以画像只给「偏爱自刀」这一倾向描述，不断言只算第一天。另需与自爆区分：自爆 6546 次、与 `zidao_num` 相关仅 +0.386，是两个独立字段（自爆见自算 `self_destruct_rate`）。

### 冲锋、投狼队友与倒钩
冲锋票（狼投好人）、投狼队友票（狼投狼队友，好人视角投对）是客观票型，描述打法倾向（激进 vs 潜伏）。自算画像把「狼投狼」拆成两个口径：

- **投狼队友率（广）**：该狼所有非弃权白天票里投向任意狼队友的占比，只看阵营、不分目标身份，衡量整体潜伏还是冲锋。
- **倒钩率（窄）**：对跳局（真预言家＋悍跳狼同场、且该狼非悍跳本人、当天投过票）里，该狼投向**悍跳狼队友**的局数占比。「倒钩」在自算指标里专指这种借好人刀清掉自家悍跳狼、装好人取信的高价值背叛；投向非悍跳狼队友只计入投狼队友率，不计入倒钩。

质量由后续存活与胜负按落差模型判（见 [`evidence-method.md`](evidence-method.md)）。用死因＋阶段定位死法：白天被放逐或被神技清掉为取信失败，夜里被自刀为战术牺牲。**倒钩后存活率**只挂真倒钩（投悍跳狼队友）的局：投任意狼队友跨好几天、没有明确战术时点，存活无从归因，故广义投狼队友率不配存活率。投向真预言家、促成白天抗推的冲锋价值最高，可半归个人。官方狼人评选把冲锋票排在倒钩票之上是当局评选分口径，与画像的质量特性分开。

## 主导与取信

### 警长率
当选警长要拿到全场多数警徽票，反映取信力与话语权：好人当选偏组织力与主线主导，狼当选是悍跳上位、控归票的直接证据。分母只能用场次（接口无“上警次数”字段），降级披露；结合当选局的胜率、得分和站边读。

## 身份与版型混杂

- 暴露型神职夜间出局率高，与平民分开比存活。
- 白痴、守卫、女巫、摄梦等身份及保护机制改变“活着”的含义。
- 狼王、狼美人、血月使徒等身份主动追求出局收益，低存活是身份特性。
- 石像鬼、梦魇、怪盗狼王等特殊狼的行动空间不同于普通狼，特殊狼成绩单独归属。
- 屠边方向（屠神／屠民）系统性影响神职与平民存活，是身份存活率的第一层基线，见 [`survival.md`](survival.md)。
- 不同赛季的阵营胜率和计分规则漂移，生涯结论用近期切片复核。

存活率解释见 [`survival.md`](survival.md)。
