# 指标解释

本页说明常见指标可以支持什么、容易被什么混淆。字段精确计分仍以官方规则资料为准。

## 场次、得分与胜率

### 场次

场次影响结果稳定性，但不能消除年代、赛区、对手、门派、版型和规则变化。老选手的大样本可能混合多个环境；新选手的小样本容易被单次赛事放大。

### 场均分与总分

场均分包含阵营基础分、评选、人命、投票、身份附加分和违规扣分，是综合结果，不是纯发言能力。

- 只在同阵营、相近计分版本内比较。
- 高场均 + 高胜率可能主要来自阵营基础分，需结合人命、评选和败局得分。
- 高场均 + 普通胜率更支持个人附加分能力；高胜率 + 普通场均更接近团队结果兑现而个人附加分有限。
- 总分首先反映参赛量，不代表单位表现。

### 胜率

胜率衡量团队结果兑现，受同伴、对手、版型和赛区强度影响。它不能单独证明判断准确、发言主导或个人能力。近期胜率变化还要检查阵营、身份和对手构成。

## 评选与人命

### MVP、尽力与背锅

- MVP支持胜局中的相对贡献，但受同阵营队友表现和官方评选顺序影响。
- 尽力支持败局中的相对贡献，不等同于获胜能力；高尽力率也可能伴随较多败局。
- 背锅是负面结果线索，需结合身份、人命、投票和违规。低背锅不等于没有错误。
- 次数应换算成对应阵营或身份场次的比率并显示分母。

### 人命值

人命吸收投票和技能造成的结果，也受主导、参与和技能结算规则影响。高人命支持“行为产生有效出局”，不等于纯识人能力。预言家查验、女巫毒、警长归票和狼人悍跳产生人命的路径不同，应结合身份和具体行为拆分。

## 好人判断指标

### 投狼率

投狼率描述投票目标阵营，不直接描述投票时机、主导性或当时信息量。已公开狼人后的跟票不能与首轮独立投中等价。优先区分首轮、关键轮次、公开信息后投票和改票。

### 站对边率

站对边率更接近预言家对跳或阵营主线选择。与投狼率联用可形成初步模式：

| 投狼率 | 站对边率 | 初步解释 | 需要验证 |
|---|---|---|---|
| 高 | 高 | 单点和主线较稳定 | 是否发生在关键轮次、是否主导 |
| 高 | 低 | 能投中具体狼人，但可能跟错预言家或后置修正 | 首次站边、改票和票序 |
| 低 | 高 | 主线跟对，独立找狼或外置位处理可能较弱 | 是否主要跟随真预言家 |
| 低 | 低 | 判断和主线均有风险 | 身份、赛季和版型偏差 |

### 警徽投对率

警徽投票多发生在信息较少的早期，可补充早期判断。候选结构、退水、自爆和投票资格会改变分母，因此不能替代白天持续站边数据。

### 身份技能率

女巫毒狼率、猎人带狼率、预言家验狼率、侦探翻狼率反映目标结果，但选择难度不同。必须展示事件分母，并结合对应身份场次、场均和胜率。小样本的 0% 或 100%只能作为线索。

## 狼人行动指标

### 悍跳次数与成功率

悍跳成功率支持正面身份竞争能力，还需检查起跳身份、警徽归属、真神出局、本人出局阶段和狼队赛果。未悍跳可能来自连续摸狼强制悍跳规则、团队分工或特殊身份，不能直接解释成胆量或偏好。

### 刀神率

狼刀是团队动作。个人页刀神率只能描述“该玩家所在狼队的刀型结果”；没有夜间讨论或个人提刀记录时，不能归因为个人找神能力。个人可归属的特殊狼主动技能应另行分析。

### 自刀

自刀是战术选择线索，不天然正面或负面。需结合是否骗药、是否形成身份收益、最终胜负和该局得分。

### 冲锋与倒钩

- 关键轮次、警徽票及持续发言支持悍跳狼并取得收益，才支持有效冲锋。
- 队友已无法挽救时投队友通常是低成本切割。
- 早期有成本地投队友、取得身份并在后续推动好人出局，才支持有效倒钩。
- 切割若没有取得身份或损害狼队轮次，不是高质量倒钩。

## 身份与版型混杂

- 暴露型神职更容易夜间出局，不能与平民直接比较存活。
- 白痴、守卫、女巫、摄梦等身份及保护机制会改变“活着”的含义。
- 狼王、狼美人、血月使徒等身份可能主动追求出局收益，低存活不等于弱。
- 石像鬼、梦魇、怪盗狼王等特殊狼的行动空间不同于普通狼，特殊狼高分不能证明普通狼能力。
- 不同赛季的阵营胜率和计分规则会漂移，生涯结论需要近期切片复核。

存活率因机械耦合和竞争解释较多，见 [`survival.md`](survival.md)。
