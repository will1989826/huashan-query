# 好人阵营表现模式

以下模式用于组织证据，不是玩家的固定属性。使用前需满足必要证据、检查反证，并报告置信度和适用身份。

## 稳定逻辑核心

**必要证据**：投狼率和站对边率均高于同范围基线；关键轮次仍准确；场均或人命不低；优势不只出现在有信息身份。

**反证**：命中主要来自公开狼人后的跟票；平民样本明显弱；较多背锅或早期白天出局说明说服、取信或复盘口径仍有问题。

## 点狼强、站边弱

**必要证据**：投狼率明显高于基线而站对边率偏低，T2 中可见早期跟错预言家、后续投中外置位狼或较晚修正。

**反证**：差异来自不同赛季或分母过小；投狼集中在公开狼；首次站边其实正确但汇总口径未记录变化。

## 跟线型好人

**必要证据**：站对边率高于投狼率，跟随真预言家的投票较稳定，但独立外置位命中和主导人命有限。

**反证**：经常先于预言家提出狼坑，或高人命来自主动主导。没有发言资料时，不应把“跟线”写成消极评价。

## 强神弱民

**必要证据**：多个有代表性的神职样本在场均、胜率、人命或有效技能上持续高于平民，且近期仍存在差异。

**反证**：仅一个神职的 1–3 场极端值；神职高分完全由阵营胜利构成；平民近期已经逆转。

## 强民弱神

**必要证据**：平民大样本表现稳定，多个神职的技能、人命或结果偏弱。可以支持“裸视角处理较稳、技能决策仍有风险”的假设。

**反证**：神职低分主要来自高夜间出局率、固定身份暴露或版型困难，而不是技能错误。

## 残局型好人

**必要证据**：好人胜局和长局中存活较高，D3+ 投票、人命或改票仍产生正贡献，存活局场均不低。

**反证**：高存活主要出现在狼人胜局、低威胁平民或短局；存活时仍低分低命中。后者只能称“活得久”。

## 高威胁好人

**必要证据**：D1/D2 夜间出局率较高，且出局前有身份信息、正确站边、人命或持续高分；控制身份后仍成立。

**反证**：早死来自固定暴露身份、技能失误、同守同救或随机首刀。仅凭低存活率不能称高威胁。

## 易被抗推或取信不足

**必要证据**：好人在 D1/D2 大量白天出局，尤其集中在平民和低信息身份；若投票和站边不差却仍频繁被放逐，更支持表达或取信问题。

**反证**：白天出局主要由猎人开枪、骑士决斗、侦探指定等技能结算造成。缺少 T3 时，只能描述取信结果，不能断言具体发言内容差。

## 跨模式表现结构

### 稳定输出

场均、胜率、评选和人命在多个赛季、身份与近期切片中方向一致。总场次大本身不能定义稳定。

### 高上限、高波动

高 MVP 同时伴随较高尽力或背锅、得分方差较大、身份间差异明显，且高低极端局均较多。没有逐场分布时，只能写“身份差异明显”。

### 团队结果型

胜率较高但场均、人命和 MVP 普通，可能支持团队适配或稳定完成分工。不能贬义写成“躺赢”，也不能把团队结果全部归功于个人。

### 败局贡献型

胜率普通或偏低，但败局得分、人命和尽力率较好。它描述逆风贡献，不保证关键时刻一定可靠。

## 禁止的捷径

- 高投狼率 = 发言逻辑强；
- 高站对边率 = 独立判断强；
- 高胜率 = 个人能力强；
- 某身份 100% = 擅长该身份；
- 低存活 = 高威胁。

这些结果都要结合时点、身份、分母、贡献和竞争解释。
