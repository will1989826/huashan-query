# 存活率解释

存活率不是独立能力分。解释前先确认官方字段的最终存活口径；没有分子、分母时，不从四舍五入的百分比反推人数。

存活结果至少要按 `阵营 × 胜负 × 身份` 拆分。T2 可用时，再比较 D1、D2、D3+ 出局、夜间出局、白天出局、最终存活及牌局持续天数。

## 好人存活率

高好人存活率至少有四种竞争解释。

### 有效残局生存

高存活同时伴随较高场均、胜率、MVP/尽力、关键轮次投对或人命，并且主要出现在好人胜局和较长牌局，支持“活到后期且持续产生正收益”。

若只是活到结束，却没有 D3+ 的判断、投票或出局贡献，只能称高存活，不能称残局强。

### 低威胁存活

高存活但场均、胜率、人命和评选均偏低，尤其集中在平民或好人败局，支持“狼队不急于处理”的假设。它不能直接证明划水，还可能来自团队分工、发言资料缺失或短局结构。

### 身份与保护收益

平民、白痴、守卫保护、女巫救人和摄梦等会改变出局概率。先按身份比较，再检查保护和技能时间线。不能把机制带来的生存全部归为隐藏身份或抗刀能力。

### 牌局长度与赛果效应

快速结束会留下更多存活者。狼人获胜时幸存的好人也没有完成好人阵营目标，因此总体存活率可能主要记录了对局长度和赛果，而不是个人能力。

## 验证好人存活的组合

至少联看以下数据：

- 好人胜局与败局的最终存活率；
- 平民与各神职的存活率；
- D1/D2 夜间出局率，用于判断威胁、身份暴露或固定身份风险；
- D1/D2 白天出局率，用于判断抗推和取信问题；
- 存活局与出局局的场均、人命、投票和评选；
- D3+ 的关键轮次表现；
- 牌局持续天数以及保护、救人等角色机制。

常见组合的安全表述：

| 组合 | 可以支持 | 仍需排除 |
|---|---|---|
| 高存活 + 高输出 + 胜局集中 | 有效残局生存 | 身份保护、短局效应 |
| 高存活 + 低输出 + 败局集中 | 低威胁存活假设 | 团队分工、身份结构 |
| 低存活 + 高输出 + 夜间早死 | 高威胁或身份暴露 | 固定暴露身份、随机首刀 |
| 低存活 + 投票不差 + 白天早出 | 取信或抗推问题 | 技能结算造成的出局 |
| 低存活 + 低输出 | 早出局限制贡献或整体表现弱 | 出局原因、身份难度 |

“低存活 + 高输出”不能自动解释为狼队忌惮，也可能是主动挡刀、身份暴露或容易被放逐。

## 狼人存活率

多数版型中，好人获胜需要狼人全部出局，因此狼人最终存活与狼人胜率机械耦合。两者默认只是一份结果信号，不能同时列为两条独立证据，也不能用高存活直接证明深水能力。

更有区分度的组合包括：

- 普通狼高后期存活 + 低悍跳 + 较少无收益的早期出局 + D3+ 推动好人出局，支持深水或后置经营假设；
- 低存活 + 悍跳/自爆/冲锋 + 狼队较好赛果 + 人命、警徽或评选收益，支持前置工作或牺牲位假设；
- 低存活 + 低贡献 + 狼队低胜率，更接近抗推或任务完成不足，不能美化成牺牲位；
- 高存活仅集中在特殊狼身份，应优先归因于身份机制和角色构成，不能泛化为普通狼能力。

判断狼人存活必须联看悍跳与否、出局日和原因、普通狼/特殊狼、胜负条件、MVP/尽力、人命、警徽、冲锋/倒钩票及后期收益。缺少 T2 时，只能称“高存活型”或“早出局型”，不能定性为深水狼或牺牲位。

## 深水与牺牲位的最低条件

称为“深水或后置经营”至少需要：普通狼样本、D3+ 存活或最后存活狼记录，以及后期投票、人命或胜局推进中的一种主动收益。仅有狼胜率和最终存活不够。

称为“前置工作或牺牲位”至少需要：D1/D2 出局记录、一项可见任务行为（如悍跳、自爆或有收益的冲锋），以及一项交换收益（如警徽、真神出局、人命或狼队轮次优势）。仅有早死和团队获胜不够。

## 禁止的等式

- 高好人存活率 = 会藏身份或残局强；
- 低好人存活率 = 狼队害怕；
- 高狼人存活率 = 深水狼；
- 低狼人存活率 + 高狼人胜率 = 牺牲位。

这些只能作为待验证假设，必须经过身份、胜负、出局时点和行为收益拆分。
