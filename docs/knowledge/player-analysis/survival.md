# 存活率解释

存活率反映出局风险，不是独立能力分。先确认官方字段的最终存活口径；没有分子分母时，不从百分比反推人数。存活按 `阵营 × 胜负 × 身份` 拆分；详情全量重建后，再分首夜死（无站边信息）、D2+ 夜死、白天放逐、白天技能出局、最终存活及牌局持续天数。

## 威胁信号按身份归一

狼默认屠神：神能自证技能、白天推不掉，只能夜里刀；民无硬逻辑自证，白天可被抗推。因此“被刀”按身份读：

- **神职夜死是常规屠神**，威胁信号弱；女巫、预言家等高价值神被刀由身份价值决定。
- **平民夜死是强威胁信号**：狼把本该给神的刀用在这个民，说明把他当威胁或误判成神。
- 神职算“高威胁”的条件：在本可不被优先刀时仍被刀，或被刀明显偏离屠神顺位。

## 好人出局分类

### 首夜死 ／ 无对跳（无站边信息）
本局没白天或没形成对跳，站边不成立。按身份归一读：神（尤其女巫）首夜死为默认高价值靶；平民首夜死为相对强信号（狼首刀误判，或把他当威胁）。两者都不归本局发言。

### D1 白天之后出局（站边×结局）
按落差模型的好人矩阵读（见 [`evidence-method.md`](evidence-method.md)）：站对边被白天放逐＝取信失败；站对边 D2+ 夜死＝高威胁（平民尤强）；站错边存活＝发言好、人狼状态不统一；站错边被放逐＝判断错被带走。

## 屠边方向作基线

屠边方向是身份存活率的第一层基线。狼挑更好屠的一边：

- 神职存活低，先归因“这批局屠神为主”，再看个人威胁。
- 平民存活高，先归因“屠神为主、民被放着”，再看个人。
- 屠民胜局里存活的民是显著信号（在被屠那边活下来）；屠神胜局里存活的民是常规。
- 派生统计：该选手所在局的屠神／屠民分布，作神职、平民存活率的基线。

## 好人存活率条件化读法

高好人存活率按伴随信号定性；屠边方向与牌局长度是所有组合的前置基线：

| 组合 | 支持 |
|---|---|
| 高存活 + 高输出 + 胜局集中 | 有效残局生存（活到后期并持续产出） |
| 高存活 + 低输出 + 败局集中 | 低威胁被留（狼队不急于处理） |
| 低存活 + 高输出 + 平民 D2+ 夜死 | 高威胁或身份暴露 |
| 站对边 + 白天被放逐 | 取信或抗推问题 |
| 保护型身份（守卫、女巫救、摄梦、白痴）高存活 | 身份机制生存 |

联看好人胜局与败局的最终存活率、屠边分布、平民与各神职存活率、首夜与 D2+ 夜死、结合站边的白天出局、存活局与出局局的场均人命投票评选、D3+ 关键轮次、牌局天数与保护机制。快速结束和狼胜局会留下更多存活者，总体存活率也记录对局长度和赛果。

## 狼人存活率条件化读法

狼人最终存活与狼人胜率机械耦合，两者算一份结果信号，用存活天数区分个人：

- 普通狼 D3+ 存活 + 低悍跳 + 少无收益早出 + D3+ 推动好人出局 → 深水或后置经营。
- 低存活 + 悍跳／自爆／抗推真预言家的冲锋 + 狼队好赛果 + 警徽／真神／人命收益 → 前置工作或牺牲位。
- 低存活 + 低贡献 + 狼队低胜率 → 抗推或任务完成不足。
- 高存活集中在特殊狼身份 → 身份机制与角色构成。

联看悍跳与否、出局日和原因、普通狼／特殊狼、胜负条件、MVP／尽力、人命、警徽、冲锋／倒钩票及后期收益。

## 深水与牺牲位的最低条件

- **深水或后置经营**：普通狼样本、D3+ 存活或最后存活狼记录，以及后期投票、人命或胜局推进中的一项主动收益。
- **前置工作或牺牲位**：D1/D2 出局记录、一项可算任务（悍跳、自爆或抗推真预言家的冲锋），以及一项可算交换（警徽、真神出局、人命或狼队轮次优势）。
