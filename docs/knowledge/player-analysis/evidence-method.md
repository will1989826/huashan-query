# 证据方法

选手画像是一组可复核的证据论证，只建立在投票、行为、存活、胜负这些客观数据上。按能否复算，判断分成三档，这是结论强度的总闸门。

## 三档判断强度

- **A 档 · 客观可自算**：来自身份全公开的单局重建，可复算、可回溯——投票（投谁、投狼与否、站对边与否、警徽投向、改票、弃票）、出局（时点、死因、站边×结局、存活天数）、结构（屠边方向、牌局长度）、票型（悍跳天与身份、自爆时机、冲锋票、倒钩票）、技能命中（验狼／毒狼／带狼／翻狼等目标阵营）、纪律（违规、DQ）。A 档可直接下“支持”。
- **B 档 · 半客观**：票型和站边客观，发言、取信这类特质由落差模型推断（见下节），只下“倾向”。
- **C 档 · 不设维度**：发言的具体逻辑与内容、夜间谁主导团队决策、心理动机没有数据支撑，画像不设这些维度。普通狼刀法归团队级，不归个人。

## 落差模型（B 档）

冲锋、倒钩、站对边、站错边是客观票型。发言与取信特质来自“行为按理应得的待遇”与“实际存活／胜负”之间的落差。特质需跨局重复才成立，单局作线索。狼人用存活天数（最终存活与狼胜机械耦合）；好人存活未与好人胜耦合，最终存活可用，按胜负修正读。

### 狼人

| 行为 | 结局 | 判断（含原因） |
|---|---|---|
| 倒钩（投狼队友，好人视角投对） | D2 后白天被清 | 发言差：好人认其投对仍留不住，取信失败 |
| 倒钩 | 活得久 | 取信成功、发言好 |
| 冲锋（投好人），悍跳狼已出局 | 仍存活 | 发言好：暴露立场仍能洗清 |
| 冲锋 | 白天被清 | 发言一般：冲锋即暴露 |

悍跳狼在世期（尤其绑票速推获胜），队内其他狼的存活由悍跳狼 carry，计为悍跳狼取信好，不计冲锋狼发言；冲锋狼要在悍跳狼出局后仍存活，才归为其发言好或人狼状态不统一（拿好人常错、被包容，跨局判）。绑票速推获胜的局靠票权不靠说服，个人存活的发言含义整体削弱。

### 好人

D2 起预言家身份已明，倒钩视为投对、站对边视为站对；投对／站对却被投死即发言有问题（狼倒钩与好人站对边同理）。

| 站边 | 结局 | 判断（含原因） |
|---|---|---|
| 站对边 | 白天被投票放逐 | 发言差：判断对却没能取信 |
| 站对边 | D2+ 夜死 | 高威胁：演对了才被刀，平民尤强 |
| 站错边 | 存活到终局 | 发言好、人狼状态不统一：错了仍逃过清算（跨局判） |
| 站错边 | 白天被投票放逐 | 判断错被带走 |

站错边的结局按胜负修正：活到好人胜为队友赢，活到狼胜为低威胁被留。狼人绑票速推结束、预言家未澄清的局不纳入。

## 数据层级

| 层级 | 数据 | 适合回答 |
|---|---|---|
| T0 | 官方选手汇总 | 场次、场均分、胜率、存活率，及官方口径的投狼率、站对边率、评选与技能比率 |
| T1 | 全部逐场索引 | 身份、版型、日期、得分、胜负、MVP、尽力、背锅 |
| T2 | 单局复盘 | 每日投票、警徽、悍跳、技能、出局时间线、最终存活 |
| T3 | 录像或可信文字复盘 | 发言逻辑、工作量、说服过程、临场修正 |

T2 全量重建后聚合为 A 档自算派生统计，每日票型、出局阶段、技能目标、站边、屠边都成为可跨生涯统计的指标。投狼率、站对边率有官方 T0 与自算 T2 两个来源，定义与分母不同，分别报告、不合并。深层行为判断（存活原因、关键轮次、冲锋、倒钩、牺牲位、深水）用 T2；发言风格与临场逻辑属 C 档。官方汇总与逐场接口可能覆盖不同赛事，分别报告各自场次、时间范围、缺页、未知身份和异常赛季。

## 重建不确定性

自算派生统计来自单局重建，客观事实（花名册、逐日投票、放逐、死亡序列、最终存活）可靠，个别版型机制为近似（怪盗狼王技能态免疫、狼王／白狼王带人、投票与死亡序列冲突的 doubt 标记）。重建失败的局（form2 缺失或损坏）不进自算指标、仍进 T1 计数，并报告覆盖率。

## 基线与切片

- 先在同一阵营内比较，好人与狼人的基础胜率、职责和计分机会不同。
- 建立所选人群的加权基线，有同赛区、同赛季总体数据时补外部基线；本组相对位置不等于全体排名。
- 切片固定为 **全生涯 ／ 自然年 ／ 最近 N 场同阵营**，各带真实分母，不做跨切片加权混合；N 为可配置窗口。
- **时效描述符**说明数据陈旧：距上次参赛时长、数据赛季跨度、各切片样本量、可重建覆盖率。
- 按普通／特殊身份和高频身份拆分；角色构成相近时，近期与生涯的差异才算状态变化。
- 控制版型和规则版本；技能、结束条件或计分变化后，跨版型平均只作概览。
- 同一赛事、门派和相近对手会形成聚类，连续牌局不是独立实验，短期连胜不等于稳定能力。

## 推荐派生统计

- 全生涯、自然年、最近 N 场同阵营记录；
- 好人拆平民、神职和高频身份，狼人拆普通狼、悍跳狼和特殊狼；
- 存活按 `阵营 × 胜负 × 身份`，再分 **首夜死（无站边信息）／ D2+ 夜死 ／ 白天放逐 ／ 白天技能出局 ／ 最终存活**；好人出局再交叉站边对错；
- 屠边方向分布（屠神／屠民），作神职、平民存活率的基线；
- 评选用对应阵营或身份场次作分母，技能率用真实事件分母；
- 投票分首轮、关键放逐轮、公开狼后跟票、改票；
- 狼人票型分冲锋、倒钩、未投票及其阶段与后续存活／胜负；自刀按 **D1 主动 ／ D2+ 悍跳狼** 拆；
- 警长当选用场次作分母（无“上警”字段），降级披露。

分母随统计值展示；没有官方分子分母时，不从百分比反推次数。

## 论证顺序

每个主要结论依次给出：**事实**（官方值或可复算的逐场数量）、**关系**（相对同阵营基线、生涯、近期或同身份样本的位置）、**解释**（最可能形成该结果的机制）、**检验**（现有数据缺什么才能区分其他机制）。一个结论至少两个非重复信号；狼人胜率与狼人存活率、总分与场均分等机械耦合字段默认算一个信号，经胜负、身份或时点条件化后新增信息才另计。

## 置信度

| 有效分母 | 标签 |
|---:|---|
| 0–9 | 仅作线索 |
| 10–29 | 低置信 |
| 30–79 | 中等置信 |
| 80+ | 较高置信 |

这是披露规则，不是显著性检验。自算指标用自己的事件分母（站对边只算对跳日、刀神质量只算相关刀局、悍跳率只算狼场次），不借用阵营总场次。落差模型的特质按跨局重复次数计置信度。跨越多种规则环境的大样本，可能比同质小样本更难解释。

## 表达与停止条件

- 用“支持”“倾向”“与……一致”，不用“证明”“一定”“从来不”。
- 先给群体基线，再逐人分开写好人与狼人：数据支持的每条特性、证据及分母、置信度和缺失证据。
- 用聚合事实，不用单局故事替代总体分布。
- 没有发言、夜间讨论或团队提议来源时，写明不可判断，不把团队动作归个人。
- 权限、令牌或上游接口限制数据层级时，在已有证据处停止。
- 自算指标全量重建并披露覆盖率；覆盖不全时按阵营、身份、胜负和年代分层报告缺口。
- 历史统计用于复盘和赛前准备，不转写为对局中关于某玩家固定习惯的确定性数据库发言。
